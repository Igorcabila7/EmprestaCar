EmprestarCar

sistema que permite o emprestimo de carros.
Funcionalidades:
Cadastro do Dono.
Cadastro do Cliente.
Cadastrar Carros.
Cadastro de emprestimo de carro.
remover carro.
Atualizar dados de Carros.

O pagamento deve ser feito no momento do emprestimo.
Caso Atraso deve haver uma multa por hora.

Cadastro cliente:
Guid id, string nome, int idade, string BI, string Carta de conducao,string email,string numero de telefone,string Whatsapp,array endereco.

Cadastro Dono:
Guid id,  string nome, int idade, string BI,  string email,string numero, string email, string whatsapp,string endereco

cadastro de carro:
Guid id, string idDono, string nome do carros,marca,Modelo,Cor,Caixa,Motor,string Matricula, km, Combustivel,array endereco.
